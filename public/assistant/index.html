학습 지식창고
블로그·영상·자료를 AI가 읽고 핵심 원칙, 절차, 판례, 주의점으로 정리해서 학습합니다. 원문은 저장하지 않고 정리된 내용과 출처만 보관합니다. 학습한 내용은 설계사들의 질문에 자동으로 활용됩니다. (상무님만 볼 수 있습니다)
① 네이버 블로그 학습
② 유튜브 영상 학습
영상 주소를 넣으면 자막을 자동으로 가져와 학습합니다. 자동으로 안 되면 영상 아래 "더보기 → 스크립트 표시"의 글을 복사해 아래 칸에 붙여넣으세요.
③ 첨부 파일(PDF) 학습
표가 많은 자료(보험료 비교 가이드북 등)는 "이미지로 읽기"를 권장합니다. 36쪽 기준 약 5~10분 걸립니다.
④ 글 붙여넣기 학습
⑥ 보험 약관 올리기 (여러 파일 한 번에)
약관 PDF를 한꺼번에 선택해서 올립니다. 글자를 그대로 쪽별로 보관하므로 비용이 거의 들지 않고, AI가 요약하지 않습니다. 파일 이름이 상품 이름으로 쓰이니 "보험사_상품명_약관.pdf"처럼 지어 주세요. 이미 올린 파일은 건너뜁니다. (글자가 선택되는 PDF, 파일당 40MB 이하)
⑦ 보험사 약관 자동 수집
보험사 공시실에서 약관 PDF를 서버가 직접 내려받아 저장합니다. 먼저 "수집 시험"으로 목록과 1건 내려받기를 확인한 뒤 "수집 시작"을 누르세요. 한 번에 10건씩 처리하며, 다시 누르면 이어서 진행합니다(이미 받은 약관은 건너뜁니다).
수집 기준 — 용량을 아끼기 위해 필요한 종류의 최근 약관만 받습니다. 약관 이름에 적힌 날짜(예: 20260701, 26.10)로 기간을 판단하고, 날짜를 알 수 없으면 포함합니다. 종류는 이름으로 분류하며 애매한 것은 AI(OpenAI)가 이름만 보고 한 번 더 판단합니다.
⑤ 약관 공시실 접속 시험
AI비서 서버가 보험사·협회 공시 사이트를 열 수 있는지 시험합니다. 한 줄에 주소 하나씩 입력하세요. (저장하지 않습니다)
다운로드 방식 조사 — 한 줄에 "보험사 | 주소 | 찾을 글자1, 찾을 글자2" 형식 (저장하지 않습니다)
